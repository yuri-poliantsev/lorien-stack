# Lórien 02, strict side elevation, two branch tiers

Variation under test: frame 01 read back as a "frontal canopy-height view" with only
six platforms. This frame forces a flat side elevation and puts the eight flets on two
clearly separated branch tiers so they are countable without tracing.

## Metaphor mapping

Same as `01.spec.md`: bot is a flet, working is a burning gold lantern with a figure at
a writing stand, idle is a low amber lantern with the figure seated, asleep is a dark
flet with one firefly pulse at the rail, the action label is a hanging wooden sign.

## Legibility at a glance

Four flets on a high branch and four on a lower branch, none overlapping, so the count
survives a two-second look. Lantern brightness alone separates working from asleep.

## All-asleep state

Silhouettes hold against the lighter dusk sky and firefly pulses mark every platform.
