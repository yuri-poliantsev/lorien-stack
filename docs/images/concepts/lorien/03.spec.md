# Lórien 03, deep parallax, three depth layers

Variation under test: whether real parallax depth survives while the flets stay
countable. Three depth layers separated by mist, which is what the implementation will
actually build as scrolling planes.

## Metaphor mapping

Same as `01.spec.md`.

## Legibility at a glance

Flets sit only on the near and middle layers; the far layer is trunks and mist with no
platforms, so depth never adds countable objects. Eight flets total.

## All-asleep state

Mist stays lit by the sky, so dark flets read as silhouettes against it.
