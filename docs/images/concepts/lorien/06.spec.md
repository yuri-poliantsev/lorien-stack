# Lórien 06, organic top-down along the branches

Variation under test: the Q16 fall-back. If 40 nametags will not fit in a side
elevation, the theme becomes an organic top-down layout where flets sit along mallorn
branches that fan across the frame. This frame is generated so the choice is made
against an image rather than a guess.

## Metaphor mapping

Same states as `01.spec.md`. Branches replace the vertical tiers as the layout spine,
and each flet gets clear space beside it for a nametag.

## Legibility at a glance

Branches fan out from the trunk so flets never collide, and there is empty canopy
around each one for a label. Eight flets, countable.

## All-asleep state

Dark flets read against the lit canopy below them.
