# StarCraft rework 04, cool palette variant

Variation under test: whether the status signal depends on a warm-on-rust palette. A
cold blue-white terrain with the same mapping proves the theme is a system, not one
lucky colour scheme.

## Metaphor mapping

Same as `01.spec.md`. Interior light stays warm so it separates from the cold ground.

## Legibility at a glance

Warm interior light against cold terrain is a stronger glance signal than warm on warm.
Eight buildings, countable.

## All-asleep state

Cold ground with eight warm beacons reads clearly.
