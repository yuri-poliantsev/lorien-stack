# Mission control 02, stats strip above the grid

Variation under test: Q13's global strip, which shows working, idle and asleep counts
plus events per minute. The strip is the theme's own status summary and must not compete
with the cards.

## Metaphor mapping

Same as `01.spec.md`, plus a strip across the top carrying three large counts with small
labels beneath them and one rate figure.

## Legibility at a glance

The strip is read first because the numbers are the largest type in the frame; the cards
are read second. Eight cards below it, countable.

## All-asleep state

The strip reading a high asleep count and a zero rate is a legitimate, calm state, not
an error state.
