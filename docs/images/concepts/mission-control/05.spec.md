# Mission control 05, inspector drawer open

Variation under test: Q13's inspector drawer, closed by default, whose tape rows show
tool name, path, role, timestamp and one truncated text line. This frame shows the drawer
open beside the grid so the shell owner knows how much width it needs.

## Metaphor mapping

Same as `01.spec.md`, plus a drawer along the right edge holding a vertical tape of
narrow rows, each row a line of small monospace text.

## Legibility at a glance

With the drawer open the grid must still be countable, so the drawer takes at most a
third of the width and stays on the same dark surface.

## All-asleep state

An empty tape with the grid asleep is a calm state.
