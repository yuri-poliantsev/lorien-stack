# Mission control 04, numeral-forward editorial variant

Variation under test: Q17 asks for big type and restrained colour. Frame 01 leaned on
line charts. This frame makes the number the ornament and drops the charts, which is
cheaper to implement and scales better to 40 cards.

## Metaphor mapping

Same as `01.spec.md`, except the working signal is a large numeral plus a single thin
activity bar rather than a chart.

## Legibility at a glance

At a glance the frame is a field of large numerals. Working versus asleep is numeral
brightness and the presence of the bar.

## All-asleep state

Dimmed numerals with no bars still read as a roster of eight.
