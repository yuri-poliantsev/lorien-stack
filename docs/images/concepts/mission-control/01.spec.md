# Mission control, candidate concept frame

What the watcher sees at 8 bots. Modern editorial dark dashboard, big type, cards,
restrained colour. No CRT, no scanlines, no game skin (Q17).

## Metaphor mapping

| concept | in the scene |
| --- | --- |
| bot | one card in a grid |
| working | a bright accent bar down the card edge and a live line chart inside |
| idle | card present, accent bar muted grey, chart flat |
| asleep | card dimmed to a thin outline with one small dot at the corner |
| action label | a monospace text row inside the card |
| roster overlay | a left rail of names, part of the same dark surface |

## Legibility at a glance

Working versus asleep is one accent colour against a near-black ground, readable at
a glance with no reading. Cards are a regular grid with generous gutters so eight
are countable instantly. Typography is the ornament; there is no chrome, no bezel,
no simulated hardware.

## All-asleep state

Every card an outline with a single dot. The grid still reads as eight monitored
units on a deliberate dark surface, not as a dead screen.
